# Bootstrap Portfolio

A personal portfolio website built with Bootstrap, featuring an animated gradient theme, project and solution showcases, and a contact page.

## Pages

- `index.html` / `index2.html`: home and about sections
- `solution.html`: projects and solutions
- `contact-me.html`: contact page

## Tech stack

HTML5 · CSS3 · Bootstrap · JavaScript · Bootstrap Icons

## Running

No build step is needed. Open `index.html` in a browser.
